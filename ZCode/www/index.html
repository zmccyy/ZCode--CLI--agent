+--- FEATURES ---+

+--

Multi-Provider LLM

Anthropic Claude, AWS Bedrock, Google Vertex, Azure AI Foundry, DeepSeek, and any OpenAI-compatible API — switch providers with a config flag.

--+
+--

Rich Tool System

50+ built-in tools: file read/write/edit, shell exec, grep, glob, LSP diagnostics, WebFetch, WebSearch, skills, and extensible sub-agents.

--+
+--

MCP Integration

Plug in external tools via Model Context Protocol servers. Extend the agent with custom capabilities without modifying core code.

--+
+--

Permission Control

Three run modes: Plan (preview only), Agent (ask per action), YOLO (auto-approve). Fine-grained control over every tool invocation.

--+
+--

Interactive Ink TUI

Full-screen terminal REPL with session resume, context compression, layered memory, and real-time cost tracking — built on React + Ink.

--+
+--

Scriptable & CI-Ready

Non-interactive mode with JSON output for CI pipelines. --write, --plan, --yolo, --reasoning flags for every automation scenario.

--+
+--

Persistent Tasks

Create, track, and auto-restore task lists across sessions. Background tasks with DreamTask, LocalAgentTask, and remote agent orchestration.

--+
+--

Keyboard-Driven

Fully configurable keybindings: F1 help, Ctrl+K command palette, Ctrl+R history, chord sequences, Vim-mode navigation — no mouse needed.

+--- INSTALLATION ---+

# Requires Node.js >= 18

$ bun install -g zcode
$ npm install -g zcode

# Or clone and run from source

$ git clone https://github.com/zmccyy/ZCode--CLI--agent.git && cd ZCode--CLI--agent/ZCode && bun install
// ---------------------------------------------------------

+--- QUICK START ---+

  1. Set your API key: export ANTHROPIC_API_KEY=sk-ant-... or configure ~/.claude.json for any supported provider.
  2. Run interactive mode: zcode — opens the full terminal REPL with Ink TUI.
  3. One-shot prompt: zcode -p "Refactor the auth module to use JWT" — runs non-interactively and prints the result.
  4. Run diagnostics: zcode doctor — checks your environment, provider config, and tool availability.
  5. List models: zcode models — shows all configured AI models across your providers.
  6. Explore docs: zcode help — browse the full command reference from within the REPL.
