# 渐进搬运、终局干净：Harness 以公共层为唯一运行时

**Status**: implemented（2026-09-03，v1.4 完成）—— 参考树已整体移出仓库，`src/` 现只含第一方公共层代码。

> 完成记录：v1.4 将整棵参考树（约 18.5 万行）从仓库删除，并同步收窄 lint/typecheck/test 范围到公共层。产品运行时（harness + providers + publicCli，Node ≥ 24 零构建）不受影响。

## Context

仓库底层是约 18.5 万行从 Claude Code 发布产物还原的 TS 源码（"底座树"），工程质量高但依赖 `bun:bundle` 私有构建管线、部分目录缺失，且本质是反编译的专有代码；顶层公共层（publicCli + providers，纯 JS/TS 零构建）是唯一可运行的运行时。项目定位为长期开源作品集项目，公开托管于 GitHub。

## Decision

Harness（Agent 循环、核心六件套工具、权限门、转录）在公共层新建的 `ZCode/src/harness/` 中照底座树的设计**干净重写**并逐步落地；底座树只作设计与行为参考（对照物），不进产品运行时，终局从仓库移除。运行时选 Node ≥24（原生 TS 类型剥离，零构建步骤），不依赖 Bun。

## Considered Options

- **(a) 直接复活底座树当产品本体** — 最快，但产品永久绑定反编译的专有代码，公开仓库有下架/法务风险 → 否决
- **(b) 完全干净重写、不参考底座树** — 白白放弃已验证的设计与行为参照系 → 否决
- **(c) 渐进搬运、终局干净** — 兼得设计质量与代码署名权 → **采纳**
