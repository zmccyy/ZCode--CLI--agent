## 写作风格要求

1. **标题**: 简洁、有冲击力、包含关键词
2. **描述**: 用"它是什么"→"为什么需要"→"核心优势"的逻辑
3. **功能列表**: 每条不超过20字，用 emoji 增强可读性
4. **代码块**: 包含语言标识，代码简洁可运行
5. **表格**: 用于对比、特性列表、链接集合
6. **Emoji**: 适度使用，增强视觉层次（不要滥用）

## 禁止事项

- ❌ 不要使用模糊的描述如"先进的"、"革命性的"
- ❌ 不要堆砌功能列表（超过10个重点说3-5个）
- ❌ 不要只有代码没有说明
- ❌ 不要使用低质量的截图或占位符
- ❌ 不要忽略国际化（至少中英双语）

## Writing Style Requirements

1. **Title**: Concise, impactful, includes keywords
2. **Description**: "What it is" → "Why needed" → "Core advantages"
3. **Feature List**: Max 20 words per item, use emoji for readability
4. **Code Blocks**: Include language identifier, keep code runnable
5. **Tables**: Use for comparisons, feature lists, link collections
6. **Emoji**: Use moderately, enhance visual hierarchy (don't overuse)

## Prohibitions

- ❌ Don't use vague descriptions like "advanced" or "revolutionary"
- ❌ Don't pile up features (highlight 3-5 out of 10+)
- ❌ Don't have code without explanation
- ❌ Don't use low-quality screenshots or placeholders
- ❌ Don't ignore internationalization (at least Chinese + English)

## 💡 高级技巧 | Advanced Tips

### 1. README SEO 优化
- 在描述中包含关键词
- 使用标准化的标题层级
- 添加 relevant topics/tags

### 2. 社交媒体优化
- tagline 适合 Twitter/X 分享
- 截图使用 2:1 比例
- 包含 OG 图片元数据

### 3. 持续更新策略
- 添加 "Last updated" 日期
- 更新版本号的 CHANGELOG
- 定期添加新功能截图

### 4. 多语言维护
- 优先维护 README.md (英文)
- 中文版本放在 README_ZH.md
- 定期同步两个版本
